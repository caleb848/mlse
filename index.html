Game plan for my first 90 days

This is intent, not history: how I'd start.

    Learn the pitch

    I'd sit down with Ticketing, Global Partnerships, Retail, Creative and Game Operations to learn their priorities, their calendars and how each team defines a good result. I'd map how briefs, approvals and budgets move today before changing anything.

  2. 30-60'

    Build one plan

    I'd turn those priorities into one shared campaign calendar for both clubs, with workback schedules, clear owners and a single approval path, so every team can see what's coming and what it needs to deliver.

  3. 60-90'

    Measure and adjust

    I'd set up simple reporting that ties campaign work to the numbers each team cares about, then use it to adjust. I'd also pick one repetitive task where AI or automation could save the team time, and test it small first.
